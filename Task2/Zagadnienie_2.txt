ENGLISH VERSION BELOW 
zaimplementować sieć neuronową z dwoma (lub więcej, jeśli ktoś chce) gęstymi warstwami. Użyć jej np. do rozpoznawania ręcznie pisanych cyfr z bazy MNIST. Poeksperymentować z parametrami, które można zmieniać, np. wziąć różne wielkości pierwszej warstwy. (Zależnie od implementacji, można mieć tu mniej lub więcej możliwości, np. może da się dodać trzecią warstwę, a może nie).
Propozycje implementacyjne: wygodnym podstawowym bytem jest Warstwa, która powinna mieć możliwość propagacji w przód (mając dane wejściowe) oraz w tył (mając błędy z kolejnej warstwy, uaktualnia wagi i zwraca błędy dla następnej warstwy; dobrze jakoś pamiętać obliczenia wykonane w czasie propagacji w przód). W prostszej (ale wystarczającej) wersji, możemy dawać Warstwie pojedynczy wektor wejściowy, wtedy da się naturalnie zaimplementować 'online learning'. Dla implementacji 'batch learning' lepiej, żeby Warstwa mogła dostać wektor wektorów wejściowych, czyli macierz. Kolejny byt, Sieć, może wtedy składać się z wielu Warstw, i mieć metody 'fit' i 'predict'.

ENGLISH VERSION:
Implement a neural network with two (or more, if one wants) dense layers. Use it, for example, to recognize handwritten numbers from the MNIST database. Experiment with parameters that can be changed, such as taking different sizes of the first layer. (Depending on the implementation, you may have more or less options here, e.g., maybe you can add a third layer, maybe not).
Implementation suggestions: a convenient basic entity is Layer, which should be able to propagate forward (having input data) and backward (having errors from the next layer, it updates the weights and returns the errors for the next layer; it's good to somehow remember the calculations made during forward propagation). In a simpler (but sufficient) version, we can give the Layer a single input vector, then 'online learning' can be implemented naturally. For the implementation of 'batch learning', it is better if the Layer can get a vector of input vectors, i.e. an array. Another entity, the Network, can then consist of multiple Layers, and have 'fit' and 'predict' methods.
